## 📦 Instalação

### macOS
1. Baixe o arquivo `sushigen-v1.0.1-macos.zip`
2. Descompacte (duplo clique)
3. Arraste `sushigen.app` para a pasta Aplicativos
4. Se aparecer aviso de segurança:
   - **Preferências do Sistema** → **Privacidade e Segurança**
   - Clique em **"Abrir Mesmo Assim"**

### Windows
1. Baixe o arquivo `sushigen-v1.0.1-windows.zip`
2. Extraia para uma pasta (ex: `C:\Program Files\SushiGen`)
3. Execute `sushigen.exe`
